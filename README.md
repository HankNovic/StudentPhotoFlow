# StudentPhotoFlow｜学生照片导出与处理工具

这是一个面向 64 位 Windows 10、Windows 11 的便携式图形工具，用来读取 `.xlsx` 学生信息表，把原始照片按“学号”命名后导出，并持续记录每一批次的新增、更新、重新处理和失败状态。

本工具已按提供的样表适配：A 列为“学号”，B 列为“个人免冠照片”。样表中的照片不是内嵌图片，而是带短时签名的下载链接。工具也兼容普通 Excel 浮动内嵌图片、本地图片路径和 Data URI。

## 便携版使用方法

便携版适用于 64 位 Windows 10、Windows 11，不需要安装 Python，也不需要单独安装图片或 AI 依赖。

1. 完整解压 `学生照片增量导出工具_便携版_v1.1.0.zip`。
2. 不要只复制 EXE 或 BAT；`PhotoExporter.exe`、`启动工具.bat` 和 `_internal` 文件夹必须放在一起。
3. 双击唯一的 `启动工具.bat`。也可以把 `.xlsx` 文件拖到这个 BAT 上。

启动器会自动检查内置 Python 运行时、Tkinter 图形界面和 AI 模型等关键文件。如果文件不完整或程序异常，窗口不会立即关闭，并会在当前目录生成 `启动错误.log`。AI 模型已包含在便携包中，首次换背景不需要再下载模型。

如果使用源码目录而不是便携版，同一个 `启动工具.bat` 会检测本机 Python 和全部基础/AI依赖；缺失时会自动安装，并把过程写入 `依赖安装.log`。不再需要另外两个安装 BAT。

## 建议操作顺序

1. 从采集系统导出最新 Excel。
2. 立即打开本工具并选择该文件。样表链接签名只在短时间内有效；过期后无法恢复，只能重新导出 Excel。
3. 点击“检查表格”，确认工作表、表头行、学号列和图片列。
4. 选择输出目录和可选处理功能。
5. 点击“开始增量导出”。

原图始终保持服务器返回的原始字节，不会因为开启换背景而被覆盖。处理结果单独保存在“处理后图片”目录。

## 增量规则

- 首次出现的学号：记为“新增”。
- 同一学号的照片对象发生变化：记为“更新”。
- 状态中已有照片但磁盘文件丢失：记为“修复”。
- 原图未变，但换背景颜色、处理模式或人脸检测设置变化：记为“重新处理”。
- 原图和处理设置都没变：记为“未变化”，不会重复下载。
- 每次重新导出的签名参数会变化，但工具会忽略这些短时参数，因此不会把全部旧记录误判成更新。

如果勾选“强制重新下载已有照片”，本次所有已存在记录都会重新下载。旧版本在覆盖前会保存在“历史版本”目录。

## 输出目录

```text
导出结果/
├─ 原始图片/                 学号.原扩展名
├─ 处理后图片/               学号.jpg
├─ 历史版本/                 被更新或重新处理前的文件
├─ 批次记录/
│  └─ 批次时间/
│     ├─ 本次新增/           本批新增照片合集
│     ├─ 本次更新/
│     ├─ 本次重新处理/
│     ├─ index.html          可视化照片合集
│     ├─ manifest.csv        可用 Excel 打开的明细
│     └─ batch.json          本批机器可读记录
├─ export_state.json         跨批次增量状态
└─ 查看最新批次.html
```

`export_state.json` 采用 UTF-8 JSON，保存每个学号的来源指纹、图片哈希、输出文件、人脸数和历次批次摘要。带签名的完整照片网址不会写入状态文件，只记录去掉签名后的地址。

## 图片处理说明

- “检测人脸数量”使用 OpenCV 正面人脸检测。0 张或多于 1 张会在批次合集里标黄，需要人工复核；它不是身份识别。
- “快速纯色背景替换”适合原背景较均匀的证件照，速度快且无需额外模型。头发边缘复杂或背景杂乱时，建议改用 AI 模式。
- “AI 智能抠图换背景”使用 `rembg`。请人工抽查边缘、发丝、眼镜和衣领，任何自动抠图都不应直接替代最终证件照审核。
- 背景色默认标准蓝 `#438EDB`，也可选择白色、红色或自定义颜色。

## 命令行用法

只检查表格：

```powershell
PhotoExporter.exe "学生信息.xlsx" --inspect
```

增量导出：

```powershell
PhotoExporter.exe "学生信息.xlsx" --cli --output "D:\照片导出" --sheet "Sheet1" --id-column A --image-column B
```

启用人脸检测与快速蓝底替换：

```powershell
PhotoExporter.exe "学生信息.xlsx" --cli --output "D:\照片导出" --id-column 学号 --image-column 个人免冠照片 --face-detection --background-mode quick --background-color "#438EDB"
```

## 注意事项

- 工作簿仅作为数据读取，不会被修改。
- 便携版目标平台为 Windows 10/11 x64，不支持 32 位 Windows 或 Windows on ARM 原生运行。
- 程序为本地自建的未签名 EXE；如果 Windows SmartScreen 首次提示，请核对文件来源后再决定是否运行。
- 照片和状态记录含个人信息，请把输出目录放在有访问控制的磁盘，不要上传公共网盘。
- 同一张表中出现重复学号时，工具会跳过所有冲突行，防止照片互相覆盖。
- 如果 `export_state.json` 被手工改坏，工具会停止，不会自动清空历史。先备份并修复该文件后再运行。
